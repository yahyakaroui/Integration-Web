## 📱 Détails du projet

### 🔹 Nom de l’application
**Esprit Meal**

### 🔹 Description
**Esprit Meal** est une application web dédiée à la gestion et à la commande de repas.  
Elle permet aux utilisateurs de :
- consulter des menus,
- passer des commandes en ligne,
- visualiser leurs choix,
- naviguer dans une interface moderne, intuitive et responsive.

Le projet vise à offrir une expérience utilisateur fluide tout en appliquant les bonnes pratiques du développement web.

---

## 🛠️ Technologies utilisées

- **HTML5** – Structure des pages
- **CSS3** – Mise en forme et design
- **Tailwind CSS** – Framework CSS moderne et responsive
- **JavaScript** – Interactivité et logique côté client
- **Git & GitHub** – Gestion de versions et collaboration
- **Font Awesome** – Icônes
- **Responsive Design** – Compatibilité multi-écrans
