## 📱 Détails du projet

### 🔸 Nom de l’application
**Esprit Meal**

### 🔸 Description
**Esprit Meal** est une application web dédiée à la gestion et à la commande de repas.  
Elle permet aux utilisateurs de consulter des menus, passer des commandes et visualiser leurs choix à travers une interface moderne et intuitive.

Ce projet a été réalisé dans un cadre académique en respectant les bonnes pratiques du développement web et du travail en équipe.
